# mathtool
## Лабораторная работа №1
Задача лабораторной работы: разработать консольное приложение для решения алгебраических уравнений вида *A·x² + B·x + C = 0*, где *A*, *B*, *C* — коэффициенты уравнения, задаваемые пользователем. Приложение вычисляет и выводит действительные корни уравнения.
Программа находится в одном файле: *mathtool.py*, а набор тестов к ней прилагается в файле *tests.txt*
