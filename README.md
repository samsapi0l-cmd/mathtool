# mathtool
### Консольное приложение для решения математических задач
Решение алгебраических уравнений, числовое интегрирование методом левых прямоугольников, сумма числового ряда, и показатели числовой последовательности, заданной пользователем
## Лабораторная работа №1
Задача лабораторной работы: разработать консольное приложение для решения алгебраических уравнений вида *A·x² + B·x + C = 0*, где *A*, *B*, *C* — коэффициенты уравнения, задаваемые пользователем. Приложение вычисляет и выводит действительные корни уравнения.
Программа находится в одном файле: *mathtool.py*, а набор тестов к ней прилагается в файле *tests.txt*
## Лабораторная работа №2
Доработать приложение, добавив три новые команды. Расчётную часть приложения разместить в отдельных модулях. Новые команды: *stats* — показатели числовой последовательности, *series* — сумма числового ряда, *integrate* — численное интегрирование методом левых прямоугольников. Разбор параметров командной строки переписан на *argparse* с поддержкой подкоманд, приложение разделено на точку входа (*mathtool.py*), разбор параметров (*cli.py*) и расчётную часть (*пакет calc/*).
